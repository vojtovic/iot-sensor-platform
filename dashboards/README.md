# dashboards/

Grafana dashboardy exportované jako JSON (Fáze 5 roadmapy).

Plánované panely:

- telemetrie po budově / místnosti (CO₂, teplota, vlhkost…),
- zdraví zařízení (online/offline přes LWT, last seen),
- monitoring systému (throughput, ingestion lag, velikost DB),
- alerty (práh CO₂, zařízení offline).

Export: Grafana → Dashboard → Share → Export → Save JSON sem.
