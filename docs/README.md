# docs/

Návrhová a rešeršní dokumentace.

- **Rešerše** (bod 1–2): architektury IoT, srovnání protokolů, platforem, databází.
- **Návrh** (bod 3, 6, 7): architektura, datový model, protokol, registrace.

  (proč MQTT 5, proč daná DB, který backend stack vyhrál benchmark…).

Diagramy piš v Mermaid přímo do `.md` (renderuje se na GitHubu) nebo ukládej
obrázky sem.
